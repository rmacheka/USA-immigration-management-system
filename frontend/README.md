# USA Immigration Management System - Frontend

This is the frontend component of the USA Immigration Management System, developed by Emmanuel.

## Features

- **Modern Dashboard Interface**
  - Clean and intuitive design
  - Responsive layout for all screen sizes
  - Real-time statistics and updates

- **User Interface Components**
  - Navigation sidebar with quick access to all features
  - Search functionality with instant results
  - Data tables with sorting and filtering
  - Status indicators for applications
  - Action buttons for common tasks

- **Interactive Features**
  - Real-time search functionality
  - Sortable data tables
  - Notification system
  - Mobile-responsive design
  - Quick action buttons

- **Data Entry Forms**
  - Application submission forms
  - Search interfaces
  - Filter controls
  - Data validation

## Project Structure

```
frontend/
├── css/
│   └── styles.css       # Main stylesheet
├── js/
│   └── main.js          # Main JavaScript file
├── images/              # Image assets
├── components/          # Reusable UI components
└── index.html          # Main HTML file
```

## Technologies Used

- HTML5
- CSS3 (with CSS Variables)
- JavaScript (ES6+)
- Font Awesome Icons
- Responsive Design Principles

## Getting Started

1. Clone the repository
2. Open `index.html` in a web browser
3. The application will load with sample data

## Responsive Design

The application is fully responsive and works on:
- Desktop computers
- Tablets
- Mobile phones

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Development

To modify the frontend:

1. Edit the HTML structure in `index.html`
2. Update styles in `css/styles.css`
3. Modify JavaScript functionality in `js/main.js`

## Contributing

Please follow these guidelines when contributing to the frontend:

1. Maintain consistent coding style

3. Test changes across different devices
4. Update documentation as needed
